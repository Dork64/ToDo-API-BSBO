# ToDo API с пользовательским веб-интерфейсом

## Описание проекта

Данный репозиторий содержит учебный проект **ToDo**, включающий серверную часть (REST API) и пользовательский веб-интерфейс.

Backend реализован на Python с использованием FastAPI, frontend — в виде одностраничного веб-приложения на HTML, CSS и JavaScript без использования сторонних фреймворков.

---

## Функциональные возможности

### Backend (API)
- Регистрация и авторизация пользователей (JWT, Bearer-токен)
- CRUD-операции над задачами
- Поддержка дедлайнов и важности задач
- Автоматическое определение квадрантов Эйзенхауэра (Q1–Q4)
- Фоновый пересчёт квадрантов задач
- Фильтрация задач по статусу и квадранту
- Поиск задач по ключевым словам

### Frontend (Web UI)
- Регистрация и авторизация пользователя
- Просмотр списка задач
- Поиск и фильтрация задач
- Создание, редактирование и удаление задач
- Отметка задач как выполненных
- Клиентская сортировка задач по важности и дедлайну

---

## Архитектура проекта

Проект разделён на две логические части:

- **Backend** — REST API, реализующее бизнес-логику, авторизацию и работу с базой данных
- **Frontend** — веб-интерфейс, выполняющий роль клиента и не содержащий бизнес-логики

Все вычисления (статусы задач, квадранты, пересчёт при изменении времени) выполняются на стороне сервера. Клиентская часть только отображает данные, полученные от API.

## Подготовка окружения

### 1. Создание файла окружения

В корне проекта необходимо создать файл `.env` со следующим содержимым:

```env
DATABASE_URL=postgresql+asyncpg://<user>:<password>@<host>:<port>/<database>
API_HOST=0.0.0.0
API_PORT=8000
ENVIRONMENT=development
SECRET_KEY=ваш_секретный_ключ
```

Секретный ключ можно сгенерировать командой:

```bash
openssl rand -hex 32
```

---

### 2. Установка зависимостей

Установите необходимые зависимости Python:

```bash
pip install -r requirements.txt
```

---

### 3. Запуск backend-сервера

Для запуска сервера выполните команду:

```bash
uvicorn main:app --reload
```

После запуска API будет доступно по адресу:

```
http://127.0.0.1:8000
```

## Описание эндпоинтов API

### Авторизация и пользователи

#### Регистрация пользователя
```
POST /api/v3/auth/register
```
Тело запроса:
```json
{
  "nickname": "string",
  "email": "string",
  "password": "string"
}
```

---

#### Авторизация пользователя
```
POST /api/v3/auth/login
```
Тип запроса: `application/x-www-form-urlencoded`

Параметры:
- `username` — email пользователя
- `password` — пароль

Ответ:
```json
{
  "access_token": "jwt_token"
}
```

---

### Работа с задачами

#### Получение списка задач
```
GET /api/v3/tasks
```

---

#### Поиск задач
```
GET /api/v3/tasks/search?q=текст
```

---

#### Фильтрация по квадранту
```
GET /api/v3/tasks/quadrant/{Q1|Q2|Q3|Q4}
```

---

#### Фильтрация по статусу
```
GET /api/v3/tasks/status/{pending|completed}
```

---

#### Создание задачи
```
POST /api/v3/tasks
```
Тело запроса:
```json
{
  "title": "string",
  "description": "string | null",
  "deadline_at": "YYYY-MM-DDTHH:MM" | null,
  "is_important": true
}
```

---

#### Редактирование задачи
```
PUT /api/v3/tasks/{task_id}
```

---

#### Отметка задачи как выполненной
```
PATCH /api/v3/tasks/{task_id}/complete
```

---

#### Удаление задачи
```
DELETE /api/v3/tasks/{task_id}
```
